Setup Guide

Panduan Integrasi API Key

Dapatkan akses visual tanpa batas dengan menghubungkan akun Pexels dan Pixabay milikmu. Sepenuhnya gratis.

P

Pexels API

Ambil Key Pexels →
1

Daftar / Login Akun

Buka situs developer Pexels dan buat akun baru atau login menggunakan akun Google/Email.

2

Isi Form Aplikasi

Klik "New App", isi deskripsi singkat untuk apa API ini digunakan (contoh: "Personal portfolio app").

3

Salin API Key

Setelah disetujui, kunci (token) akan muncul di Menu Key. Salin kombinasi huruf dan angka tersebut.

Geser & Klik untuk melihat screenshot

P

Pixabay API

Ambil Key Pixabay →
1

Buka Dokumentasi API

Kunjungi halaman Pixabay API Documentation dan pastikan kamu sudah login ke akun Pixabay.

2

Temukan Parameter Key

Scroll ke bawah pada bagian "Search Images". Cari parameter bernama key yang disorot dengan warna hijau (Klik disini).

3

Salin API Key

Itu adalah API Key unik milikmu. Salin dan masukkan ke dalam kolom Pixabay di aplikasi SwitchLens.
